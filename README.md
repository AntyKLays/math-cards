# Карточки по математическому анализу

**Сайт:** https://antyklays.github.io/math-cards/

Статическая версия просмотрщика учебных карточек. Главная страница — `index.html`; данные загружаются из `mathAnal.json`, схемы лежат в `cards-visuals/matan/`.

## Публикация на GitHub Pages

Репозиторий содержит только статические файлы, сервер не нужен. Сайт опубликован из ветки `main`, папка `/ (root)`. Файл `.nojekyll` добавлен, чтобы GitHub Pages отдавал файлы без обработки Jekyll.

После изменений достаточно закоммитить их в `main` — GitHub Pages пересоберётся автоматически.

## Локальный просмотр

Из-за загрузки `mathAnal.json` через `fetch` страницу нужно открывать по HTTP, а не двойным щелчком по файлу. Из этой папки выполните:

```powershell
python -m http.server 8000
```

и откройте `http://localhost:8000/`.

## Состав

| Файл или папка | Назначение |
|---|---|
| `index.html` | просмотрщик карточек |
| `mathAnal.json` | база карточек |
| `cards-visuals/matan/` | SVG-схемы |
| `favorites.html` | разовый импорт подготовленного избранного |
| `cards-database.schema.json` | схема базы |
| `validate-cards-database.js` | проверка базы (нужен Node.js) |

## Обновление

1. Замените `mathAnal.json` и при необходимости папку `cards-visuals/matan/`.
2. При желании проверьте базу: `node validate-cards-database.js mathAnal.json`.
3. Закоммитьте изменения и отправьте их в `main` — GitHub Pages пересоберётся автоматически.

## Примечания

- Прогресс и избранное хранятся в `localStorage` браузера каждого посетителя и между устройствами не синхронизируются.
- Для шрифтов используется Google Fonts; без интернета браузер применит системные шрифты.
