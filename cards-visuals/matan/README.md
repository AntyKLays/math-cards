# SVG по математическому анализу

Учебные схемы: белый фон, крупные подписи, одинаковый масштаб осей на комплексной плоскости. Пунктир обозначает исключённую границу; пустая точка — исключённый конец. На графиках последовательностей изображены отдельные точки, а не непрерывные кривые.

Перерисовано 73 SVG. Генератор: `node cards-visuals/build-matan.js`. Он обновляет схемы, подписи в обеих базах и production-копии; содержимое карточек не меняет.

## Убраны из карточек

- `04-real-decimal.svg`: Десятичная запись повторяла текст определения без наглядного объяснения.
- `05-antisymmetry.svg`: Цепочка неравенств — текстовое доказательство, а не полезная иллюстрация.
- `05-transitivity.svg`: Дублирование простого неравенства; отдельная схема не нужна.
- `06-sup-existence.svg`: Дублирование иллюстрации верхней грани без объяснения существования.
- `06-inf-existence.svg`: Дублирование иллюстрации нижней грани без объяснения существования.
- `07-rational-power.svg`: Переоформленная формула корня без дополнительного геометрического смысла.
- `08-limit-point-infinite.svg`: Дублирование схемы предельной точки.
- `11-dot-product.svg`: Плоская проекция не объясняет данное в карточке эрмитово произведение в ℂᵐ.
